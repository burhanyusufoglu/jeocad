JEOCAD Windows Kurulum Rehberi

Programı bilgisayarınızda bağımsız masaüstü yazılımı olarak kullanın
⭐ 1. Yol: Masaüstü Kısayolunuz Hazır!

Masaüstünüze (Desktop) "BURHAN YUSUFOĞLU - JEOCAD" ve "JeoCAD" kısayolu yerleştirildi. Masaüstünüzdeki logolu simgeye çift tıkladığınız anda program tarayıcı çubukları olmadan, tıpkı AutoCAD gibi bağımsız bir pencerede açılır.

✓ Masaüstünüzde simge hazır bulunuyor
🌐 2. Yol: Tarayıcınızı Windows Uygulamasına Dönüştürün (PWA)

Kullandığınız Microsoft Edge veya Google Chrome tarayıcısında:

  1. Sağ üstteki üç nokta (...) menüsüne tıklayın.
  2. "Uygulamalar" (Apps) menüsüne gelin.
  3. "Bu siteyi bir uygulama olarak yükle" seçeneğine tıklayın.

Bu işlem JEOCAD'i doğrudan Windows Başlat Menünüze ve Görev Çubuğunuza ekler.

📁 3. Yol: Klasördeki Doğrudan EXE Dosyası

Program klasörünüzdeki JeoCAD.exe dosyasını flash bellekle başka bilgisayarlara taşıyabilir ve kurulum yapmadan doğrudan çift tıklayarak çalıştırabilirsiniz.
